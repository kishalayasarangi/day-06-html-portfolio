# Day 06 — HTML Portfolio Page

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A personal portfolio page built with pure HTML and CSS.
No frameworks, no libraries — just the basics.

## How to view
Just open `index.html` in your browser, or view it live on GitHub Pages.

## Features
- Dark themed design
- Responsive skills grid
- Projects section with GitHub links
- Smooth hover effects
- Contact section
